Accesibilidad web

Última actualización: 26/08/2026

Para este porfolio se ha tenido en cuenta la accesibilidad durante el diseño y desarrollo, tomando como referencia las WCAG 2.2 y aplicando buenas prácticas de accesibilidad web.

Desarrollo accesible

Se ha trabajado especialmente en:

  • Estructura semántica y jerarquía coherente de encabezados.
  • Enlace de salto al contenido principal (skip link) para facilitar el acceso directo al contenido.
  • Navegación mediante teclado y gestión visible del foco.
  • Nombres accesibles para enlaces y elementos interactivos.
  • Uso de ARIA y textos sr-only cuando aportan información necesaria a las tecnologías de asistencia.
  • Imágenes informativas con textos alternativos e imágenes decorativas.
  • Iconos decorativos ocultos a las tecnologías de asistencia.
  • Información previa cuando un enlace abre una nueva pestaña.
  • Contraste adecuado entre texto y fondo.
  • Diseño responsive y comprobaciones en diferentes tamaños de pantalla.
  • Navegación esencial funcional con JavaScript deshabilitado.

Evaluación

Herramientas de evalucación utilizadas:

  • WAVE (Herramienta de Evaluación de Accesibilidad Web): Permite realizar evaluaciones automáticas de accesibilidad y detectar incidencias relacionadas con la estructura y la semántica del contenido.
  • ARC Toolkit : Extensión de navegador utilizada para la auditoría de accesibilidad y la evaluación del cumplimiento de las pautas WCAG.
  • Contrast Checker (Comprobador de contraste) : Heramienta utilizada para comprobar el contraste entre texto, iconos y fondo conforme a los requisitos establecidos por WCAG.
  • HeadingsMap : Herramienta utilizada para revisar la jerarquía y estructura de encabezados del sitio.
  • Landmarks : Utilizado para verificar la correcta implementación de regiones semánticas y puntos de referencia de navegación.
  • Taba11y : Taba11y: herramienta utilizada para comprobar el orden de navegación de los elementos interactivos mediante teclado y visualizarlo gráficamente.
  • NVDA (Lector de Pantalla) : Utilizado para evaluar la experiencia de usuarios de tecnologías de asistencia y verificar la correcta interpretación del contenido. También se realizaron comprobaciones adicionales utilizando el Narrador de Windows para contrastar la experiencia obtenida con NVDA y verificar el comportamiento general de la navegación y lectura del contenido.
  • Chrome DevTools : Utilizado para realizar comprobaciones responsive y simulaciones relacionadas con diferentes condiciones de percepción visual y del color.

Las pruebas manuales incluyeron navegación mediante teclado, revisión de encabezados y landmarks, comprobación de enlaces y botones, lectura con lectores de pantalla, contraste, zoom hasta el 400 %, comportamiento responsive y funcionamiento del menú de navegación.

Resultado

Las comprobaciones realizadas permitieron detectar y revisar aspectos relacionados con la estructura, navegación, contenido alternativo, contraste e interacción con tecnologías de asistencia.

Esta evaluación no constituye una certificación de conformidad con WCAG 2.2. Refleja las pruebas realizadas y el estado del sitio en la fecha indicada.

La accesibilidad se considera un proceso continuo de revisión y mejora.
