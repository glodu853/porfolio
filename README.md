# Portafolio web — Gloria Duque P.

Portafolio profesional desarrollado para presentar proyectos de diseño y desarrollo web, junto con el enfoque aplicado en accesibilidad, usabilidad y estructura semántica.

## Tecnologías

- HTML5
- CSS3
- JavaScript con apoyo de IA.
- WordPress
- Elementor

## Accesibilidad

El sitio ha sido desarrollado tomando como referencia las **WCAG 2.2** y aplicando buenas prácticas de accesibilidad web.

Se realizaron pruebas automáticas y manuales de:

- Navegación mediante teclado.
- Estructura semántica y jerarquía de encabezados.
- Enlaces, botones y foco.
- Textos alternativos e imágenes decorativas.
- Contraste de color.
- Zoom hasta el 400 %.
- Diseño responsive.
- Navegación con JavaScript deshabilitado.
- Lector de pantalla NVDA.
- Simulación con diferentes condiciones de percepción visual y del color.

### Herramientas

WAVE · axe DevTools · ARC Toolkit · Lighthouse · Contrast Checker · HeadingsMap · Taba11y · Chrome DevTools · NVDA
